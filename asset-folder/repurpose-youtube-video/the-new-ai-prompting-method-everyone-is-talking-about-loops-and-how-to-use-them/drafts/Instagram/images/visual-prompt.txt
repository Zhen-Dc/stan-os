2. Build the loop
Body: Every useful loop needs stages: discover, plan, execute, verify, improve.

Paste/action: Before you automate the task, write the steps the task should move through.

3. Give agents jobs
Body: Agents work best when each one has one role: research, build, write, review, or coordinate.

Paste/action: Split the workflow into specialist agents instead of asking one agent to do everything.

4. Add verification

5. Use an orchestrator
Body: An orchestrator keeps the loop moving. It decides what runs, what waits, and what needs human review.
Visual block: Orchestrator -> Agents -> Review.
Paste/action: Create one agent that coordinates the workflow and hands off only the right decisions.

6. Stay in control
Body: The point is not to remove humans. The point is to move humans to judgment.
