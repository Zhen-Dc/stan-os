## Import Steps

1. Open Penpot at http://localhost:9002.
2. Create or open the file `Claude AI Marketer Social Graphics`.
3. Drag each SVG onto the Penpot canvas, or use Penpot's import option.
4. Rename the imported frame to match the SVG filename.
5. Edit text, cards, badges, colors, and layout directly in Penpot.
6. Export final PNGs back into the matching `drafts/<Platform>/images/` folder.
