Manual pain: People save long prompts but still describe their Skills too vaguely, so the automation does not fire reliably.
Automation mechanism: Turn the working prompt into a narrow Skill, write the description as the exact job, then test whether Claude triggers it correctly.
Proof or result: Public search preview says the post explains that Claude reads the 2-line Skill description when deciding whether a Skill fires, and gives the contrast: a vague writing Skill vs a LinkedIn-hook task Skill.
