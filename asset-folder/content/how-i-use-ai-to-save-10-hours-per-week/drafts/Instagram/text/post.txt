Slide 1: Save time on boring repeats
The easiest AI win is not advanced automation. It is repeated daily work.
COVER: The point is not a tool list. It is using AI on repeated daily work.

Slide 2: Start where time leaks
Find the tasks that quietly eat the week.
PIPELINE: Writing, analysis, and life admin are good starting points because they repeat and have clear first drafts.

Slide 3: Why beginners get stuck
They look for the perfect tool before choosing the repeated task.
FIX: Start with a task you already do: email, scripts, summaries, planning, notes, or analysis.

Slide 4: Shortcut vs habit
A random AI shortcut saves minutes once. A habit saves time every week.
COMPARISON: Pick one repeated task, use AI for the first pass, review it, and reuse the same process next week.

Slide 5: Use the first-pass rule
AI is best at removing the empty-page moment.
FLOW: Give it the context, ask for a first pass, add your judgment, then save the useful version for next time.

Slide 6: AI drafts. You decide.
Saving time does not mean outsourcing judgment.
RATIO: Let AI create first versions and summaries. Keep human judgment on accuracy, taste, priorities, and decisions.

Slide 7: Track the saved hours
Small repeated wins add up quickly.
PROGRESS: Look for tasks that repeat weekly, take more than 20 minutes, and end in a predictable output.

Slide 8: Save this time rule
If you do it every week, AI should help with the first pass.
SAVE THIS: Do not automate your whole life. Start with one repeated task that has a clear output.
