# VixMa

VixMa is Stanley's local AI design studio and brand asset builder.

This first version is a quick local prototype:

- Browser access at `http://localhost:8787`
- No login
- Local browser memory
- One editable LinkedIn design per image
- PNG export
- Separate folder inside `AIS-OS` so it can be moved later

Start it:

```powershell
.\VixMa\start-vixma.ps1
```

Long-term fork base:

```text
https://github.com/penpot/penpot
```

The existing local Penpot Docker reference is outside this folder:

```text
C:\Users\DELL\Master Project\Stan OS\external\penpot-local
```
